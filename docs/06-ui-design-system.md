## Typography
- Headings: Manrope
- Body: Inter
- Optional editorial accent: DM Serif Display

## Type Scale
Desktop baseline: Display 64, H1 56, H2 44, H3 32, H4 24, body-large 20, body 16, small 14, caption 12.

## Spacing
4px base scale: 4, 8, 12, 16, 24, 32, 40, 48, 64, 80, 96, 120.

## Grid
Desktop 12-column, tablet 8-column, mobile fluid/single-column. Recommended max content width 1200–1280px.

## Components
Button, Navbar, Footer, SectionHeading, Card, ServiceCard, PortfolioCard, ProfessionalCard, PricingCard, TestimonialCard, BlogCard, Input, Select, Textarea, Modal, Accordion, Toast, Loader, Breadcrumb.

## Soft UI
Use subtle elevation, rounded surfaces, calm contrast, and generous whitespace. Avoid excessive neumorphism and low-contrast controls.
