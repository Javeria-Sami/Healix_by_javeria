# 04 — User Flows

## Primary Conversion Flow
Landing → Understand → Trust → Explore Services → Evaluate Capability → Review Evidence/Plans → Resolve Questions → Contact.

## Service Flow
Home → Services → Service Detail → Benefits/Process → Related Case Study → CTA.

## Portfolio Flow
Home → Portfolio → Project → Challenge → Solution → Outcome → CTA.

## Contact Flow
Contact → Form → Client Validation → Server Validation → Processing → Success/Failure → Next Step.

## HCI Requirement
Users must never be uncertain whether an action succeeded, failed, or is still processing.
