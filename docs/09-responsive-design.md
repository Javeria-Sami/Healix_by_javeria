# 09 — Responsive Design

## Strategy
Mobile-first.

## Representative Widths
320, 375, 390, 430, 768, 1024, 1280, 1440, 1920+.

## Mobile Requirements
- Touch-friendly controls.
- Simple navigation.
- Reflowed cards.
- Responsive typography.
- Optimized imagery.
- No horizontal overflow.
- Clear primary CTA.

Mobile is a separate composition, not merely a scaled desktop.
