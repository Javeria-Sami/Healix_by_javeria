# 13 — API Documentation

Potential endpoints:

```text
GET  /api/services
GET  /api/services/:slug
GET  /api/projects
GET  /api/projects/:slug
GET  /api/professionals
GET  /api/professionals/:id
GET  /api/articles
GET  /api/articles/:slug
POST /api/contact
POST /api/newsletter
```

Server-side validation is mandatory. Frontend validation is not a security boundary.
