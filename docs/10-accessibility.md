# 10 — Accessibility

## Target
WCAG 2.2 AA principles where practical.

## Requirements
- Semantic HTML.
- Keyboard navigation.
- Visible focus.
- Proper heading hierarchy.
- Accessible form labels.
- Sufficient color contrast.
- Alt text.
- Accessible dialogs/menus/accordions.
- Reduced-motion support.
- Screen-reader-friendly controls.

## HCI Connection
Accessibility is integrated into reusable components so it is not dependent on individual page authors.
