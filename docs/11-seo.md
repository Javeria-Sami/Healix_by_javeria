# 11 — SEO

## Every Indexable Page
- Unique title.
- Meta description.
- Canonical URL.
- Semantic headings.
- Descriptive URL.
- Open Graph metadata.
- Optimized images.

## Structured Data
Use only appropriate schema types such as Organization, MedicalOrganization where accurate, Person, Article, and FAQ.

## Technical SEO
Sitemap, robots.txt, canonicalization, indexability, internal linking, performance, and broken-link checks.
