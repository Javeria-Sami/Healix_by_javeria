# 16 — Testing

## Functional
Navigation, forms, routing, filters, accordions, modals, API calls.

## Visual
Spacing, typography, alignment, colors, responsive behavior, motion.

## Accessibility
Keyboard, focus, contrast, labels, screen readers, reduced motion.

## Performance
Lighthouse/Core Web Vitals and real-device testing where practical.

## SEO
Metadata, sitemap, robots, canonical URLs, structured data, broken links.

## Security
Invalid input, injection/XSS defenses, rate limiting, API access controls.

## Definition of Done
No critical defects, no blocking console errors, responsive behavior verified, accessibility reviewed, production build successful.
